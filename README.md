# HalolGo Android — 1-versiya

Bu Flutter loyihasi HalolGo backendiga ulanish uchun boshlang‘ich Android frontend.

## Hozir ishlaydigan qismlar
- Login
- Ro‘yxatdan o‘tish
- Bosh sahifa
- Mahsulotlarning demo katalogi
- Savat
- Buyurtmalarni serverdan olish
- Profil/bonus ko‘rinishi

## Keyingi bosqich
1. `lib/services/api.dart` ichidagi `baseUrl` ni deploy qilingan server manziliga almashtirish.
2. Mahsulot katalogini admin API bilan to‘liq ulash.
3. Manzil va checkout.
4. Buyurtmani serverga yuborish.
5. Chat oynasi.
6. APK/AAB build.

## Muhim
Server hozir prototip holatida. Internetga chiqarishdan oldin autentifikatsiya va parol saqlashni xavfsizlashtirish kerak.
